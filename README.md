codyssey_project

1. 프로젝트 개요
코디세이 AI 올인원 입학연수과정 미션 1-1
목표: 터미널, DOCKER, GIT/GITHUB를 이용하여 개발환경을 구축하고 DOCKER 기반 웹 서버 실행 및 검증

2. 개발 환경
OS: Microsoft Windows [Version 10.0.26300.9711]
Shell: CMD
Terminal: VS Code Integrated Terminal
Git version: git version 2.56.0.windows.4
Docker version:d
Editor: Visual Studion Code

3. 수행 체크리스트
    1) 터미널 기본 명령어 실습
    2) 파일 및 디렉토리 권한 변경
    3) Docker 설치 및 정상 동작 확인
    4) hello-world 및 Ubuntu 컨테이너 실행
    5) Dockerfile 기반 웹서버 구축
    6) 포트 매핑 접속 확인
    7) 바인드 마운트 반영 확인
    8) Docker 볼륨 영속성 검증
    9) Git 설정 및 Github 연동
    10) 트러블슈팅 2건 이상 기록

4. 실습 및 검증 결과
실습을 진행하면서 명령어와 실제 실행 결과를 기록한다. 

5. 트러블슈팅
실제로 발생한 오류와 해결 과정을 기록한다.
